推薦價源

香港優先，國際平台作參考

Carousell HK 買入

C2C 供應多，容易搵急放盤。要用賣家評分、面交驗袋、收據完整度做風險分。

米蘭站 / Brand Off 參考 + 補貨

適合做本地零售價參考同較低風險貨源，但入貨價通常較硬，差價未必最大。

Vestiaire / eBay Sold 市價

用成交或上架價校準全球市場，特別係稀有色、尺寸同年份。正式版應分開香港可交收價同海外可比價。

客人前台

前台唔講「差價」，只呈現精品買手、已篩選、可預留、可安排驗證同交收。買家落訂後，你先去鎖定貨源，降低存貨風險。

預留 / 落訂

客人提交後，後台會生成「已收訂 → 鎖貨 → 驗證 → 交收」流程。
示範：訂金 15%，餘款交收前確認。

營運規則

呢套系統嘅重點唔係盲目搵平貨，而係控制真偽、交收、資金同聲譽風險。貴價手袋買賣最怕一件假貨或一單甩貨食晒利潤。

1. 買入評分

  • 價差至少 18% 或 HK$12,000 以上先入候選。
  • Hermes 需記錄皮革、尺寸、年份刻、配件完整度。
  • 低過市場 25% 以上自動標紅，需要二次驗證。

2. 驗證流程

  • Carousell / 私人賣家：只做面交，先驗袋後付款。
  • 高價 Hermes：收據、盒、塵袋、刻印、五金、線步全部留相。
  • 必要時用第三方驗證，成本直接扣入 ROI。

3. 落訂後鎖貨

  • 前台顯示「可預留」而非保證現貨。
  • 客人落 15% 訂金後，買手 2 小時內鎖定來源。
  • 若貨源失效，退款或轉同級貨，保護信任。
