估價可行方法

1. 官方銀行估價

最接近按揭實務，但通常要人手填地址、座數、樓層、單位；不建議自動提交。

2. CentaEstimate / 代理估價

可作第二 opinion，較易打開，但估值模型同銀行未必一致。

3. 半自動記錄

之後可以加 backend，每日提醒你開銀行頁，把估值貼入表格，然後同步 Notion / GitHub JSON。

4. 瀏覽器自動填表

技術上可做，但要你明確批准，並避開登入、驗證碼、個人資料及銀行條款風險。
